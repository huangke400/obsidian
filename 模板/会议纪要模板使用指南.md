# Obsidian 会议纪要模板使用指南

## 📁 已创建的模板文件

### 1. 完整会议纪要模板 (`obsidian_meeting_template.md`)
- **适用场景**: 正式项目会议、重要决策会议、客户会议
- **特点**: 结构完整、信息详细、包含跟踪表格
- **文件大小**: 完整的企业级会议纪要格式

### 2. SPIC标准会议纪要模板 (`spic_meeting_template.md`)
- **适用场景**: SPIC项目会议、标准化会议记录
- **特点**: 符合SPIC文档规范、结构化表格、标准格式
- **命名规范**: `项目编号_会议类型_会议纪要_会议主题_日期_版本`

### 3. 简易会议纪要模板 (`simple_meeting_template.md`)
- **适用场景**: 日常例会、团队会议、部门会议
- **特点**: 简洁明了、快速记录、重点突出
- **核心内容**: 基本信息、议程、要点、决议、行动

### 4. 快速会议记录模板 (`quick_meeting_template.md`)
- **适用场景**: 临时会议、快速记录、个人笔记、站立会议
- **特点**: 极简格式、快速填写、移动端友好
- **记录方式**: 要点式记录、行动项导向

## 🚀 在Obsidian中使用模板

### 方法1: 使用模板插件（推荐）
1. **确保模板插件已启用**
   - 打开Obsidian设置
   - 进入"核心插件"
   - 启用"模板"插件

2. **配置模板文件夹**
   - 进入"模板"插件设置
   - 设置"模板文件夹位置"为包含这些模板的文件夹
   - 保存设置

3. **使用模板**
   - 创建新笔记
   - 按`Ctrl+T`（或点击模板图标）
   - 选择需要的会议纪要模板
   - 模板内容会自动插入

### 方法2: 手动复制使用
1. 打开模板文件
2. 复制全部内容
3. 在新笔记中粘贴
4. 替换`{{变量}}`为实际内容

### 方法3: 使用快捷键
1. 设置模板快捷键
2. 快速插入常用模板
3. 提高记录效率

## 🔧 模板变量填写指南

### 通用变量（所有模板）
- `{{会议标题}}` - 会议完整名称
- `{{会议时间}}` - 日期和时间（如：2026年4月13日 14:00-16:30）
- `{{会议地点}}` - 物理地点或线上会议链接
- `{{主持人}}` - 会议主持人姓名
- `{{记录人}}` - 纪要记录人姓名
- `{{参会人员}}` - 参会人员名单，用逗号分隔

### 完整模板专用变量
- `{{会议编号}}` - 会议唯一标识（如：MEET-2026-001）
- `{{应到人数}}` / `{{实到人数}}` - 参会人数统计
- `{{议程1}}` / `{{议程2}}` - 具体议程内容
- `{{决议1}}` / `{{决议2}}` - 具体决议事项
- `{{责任人1}}` / `{{时间1}}` - 行动项详情

### SPIC模板专用变量
- `{{项目编号}}` - SPIC项目编号（如：SPIC_JTYBJ）
- `{{会议类型}}` - 会议分类（如：项目会议、评审会议）
- `{{版本}}` - 文档版本号（如：v1.0）
- `{{保密等级}}` - 文件保密级别

### 文件命名规范
1. **完整格式**（推荐）:
   - `YYYYMMDD_会议主题_会议纪要.md`
   - 示例: `20260413_清洁能源项目启动会_会议纪要.md`

2. **SPIC格式**:
   - `项目编号_会议类型_会议纪要_主题_日期_版本.md`
   - 示例: `SPIC_JTYBJ_项目会议_清洁能源启动会_20260413_v1.0.md`

3. **简易格式**:
   - `YYYY-MM-DD_简短主题.md`
   - 示例: `2026-04-13_技术团队周会.md`

4. **快速格式**:
   - `日期_主题_quick.md`
   - 示例: `2026-04-13_临时讨论_quick.md`

## 🔄 会议纪要工作流程

### 会前准备阶段
1. **选择模板**: 根据会议类型选择合适的模板
2. **预填信息**: 填写已知的会议基本信息
3. **准备议程**: 列出会议议程框架
4. **设置提醒**: 设置会议提醒和纪要截止时间

### 会中记录阶段
1. **实时记录**: 使用模板记录讨论要点
2. **标记重点**: 用符号标记重要内容和决议
3. **记录行动项**: 明确记录行动项和责任人
4. **拍照存档**: 如有白板讨论，拍照存档

### 会后整理阶段
1. **完善内容**: 24小时内完善会议纪要
2. **确认行动项**: 与相关责任人确认行动项
3. **添加标签**: 添加合适的标签便于搜索
4. **建立链接**: 链接到相关项目和人员

### 分发跟踪阶段
1. **审核分发**: 主持人审核后分发给相关人员
2. **跟踪执行**: 定期跟踪行动项执行情况
3. **更新状态**: 在纪要中更新行动项状态
4. **归档管理**: 按规范归档会议纪要

## 🆘 常见问题解答

### Q1: 如何快速找到需要的模板？
A: 将模板文件放在固定文件夹，使用Obsidian的模板插件快速调用。

### Q2: 会议纪要应该包含哪些必要信息？
A: 至少包含：会议主题、时间、地点、主持人、参会人、议程、讨论要点、决议、行动项。

### Q3: 如何确保行动项得到执行？
A: 在纪要中明确记录责任人、完成时间和交付物，定期跟踪并在下次会议中回顾。

### Q4: 会议纪要应该保存多久？
A: 根据公司规定，一般项目相关纪要保存至项目结束后2-3年，重要决策纪要永久保存。

### Q5: 如何保护敏感会议内容？
A: 设置文件保密级别，控制分发范围，必要时加密存储。
