# 有机肥等生产业务

调研分工：
1.生产业务含生产物料\BOM\工艺主数据相关业务--XX顾问
2.生产领料、报工、入库


## 一、调研目标

1. 全面梳理客户有机肥产品全生命周期业务流程，包括原材料采购、生产制造、产品入库、成本核算及销售全环节，明确各环节业务逻辑与管理需求。
2. 识别生产业务中的核心数据（如 BOM 结构、工艺参数、成本要素等），为 SAP 系统中生产模块、成本模块的配置与开发提供依据。
3. 挖掘当前生产业务中的管理难点与痛点，结合 SAP 系统功能提出优化方案，确保系统适配业务实际需求。

## 二、调研范围

客户有机肥生产相关全业务链，涵盖生产计划制定、产品定义、生产工艺执行、物料流转、成本归集、产品销售等环节，涉及生产部门、仓储部门、财务部门、销售部门等相关业务单元。

## 三、调研核心内容

### （一）生产计划管理

1. 生产计划制定依据：是否基于销售订单、市场预测、库存水平等制定计划？计划周期（日 / 周 / 月）如何设定？
2. 计划层级与内容：是否区分主生产计划、车间作业计划等层级？计划中是否明确产品产量、生产批次、生产车间、完成时间等关键信息？
3. 计划调整机制：当销售订单变更、原材料供应异常或生产设备故障时，计划调整流程是什么？调整权限如何分配？
4. 计划执行跟踪：如何监控生产计划的执行进度？是否有专门的计划跟踪报表或工具？未按计划完成的异常处理流程是什么？

### （二）产品种类与 BOM 管理

1. 产品种类划分：
    
    - 有机肥产品具体有哪些品类（如颗粒肥、粉剂肥、专用肥等）？是否按养分含量、适用作物、包装规格等进一步细分？
    - 除有机肥外，是否有其他副产品（如沼气发电余能、发酵残渣等）？副产品的利用或销售方式是什么？
    
2. 产品 BOM 结构：
    
    - 各产品的 BOM 层级的构成是怎样的？（如是否区分主原料、辅料、包装材料等）
    - 核心原材料（羊粪、粪污、秸秆等）的消耗定额是否明确？定额制定的依据是什么（如实验数据、生产经验等）？
    - 不同批次产品的 BOM 是否存在差异？若存在，差异原因及调整方式是什么？
    - 沼气作为自耗燃料，是否纳入 BOM 结构？如何体现其在生产中的消耗逻辑？
    
3. BOM 维护与管理：
    
    - BOM 的创建、修改、停用流程是什么？维护权限归属于哪个部门？
    - 是否存在替代物料（如不同来源的羊粪、秸秆替代品）？替代规则及触发条件是什么？
    

### （三）生产工艺管理

1. 核心生产工艺流程：
    
    - 有机肥生产的完整工艺路线是什么？（如原料预处理→发酵→腐熟→粉碎→混合→造粒→干燥→筛分→包装→入库）
    - 各工艺环节的关键操作要求、技术参数（如发酵温度、发酵周期、粉碎粒度、含水率等）是否明确？
    - 沼气生产工艺与有机肥生产工艺的衔接逻辑是什么？沼气产生、存储、输送及在生产中的使用环节（如干燥、加热等）如何衔接？
    
2. 生产批次管理：
    
    - 是否采用批次管理？批次编码规则是什么（如包含生产日期、原料批次、生产线等信息）？
    - 批次追溯要求：是否需要实现从原材料投入到产品产出、销售的全批次追溯？追溯的核心信息有哪些？
    
3. 生产设备与生产线：
    
    - 主要生产设备有哪些？（如发酵罐、粉碎机、造粒机、干燥机、沼气发生器等）
    - 设备是否按生产线划分？每条生产线的产能、生产产品类型、维护周期是什么？
    - 设备运行数据（如运行时长、能耗、产量等）是否记录？记录方式是手工还是自动化系统？
    

### （四）领料与物料流转管理

1. 领料流程：
    
    - 生产领料的触发条件是什么？（如基于生产订单、领料单等）
    - 领料申请、审批、发放流程是什么？涉及哪些部门及岗位？
    - 原材料（羊粪、粪污、秸秆等）的计量方式是什么？（如按重量、体积等）计量工具及精度要求是什么？
    
2. 物料流转控制：
    
    - 各工艺环节之间的物料移交如何记录？是否有交接单据？
    - 生产过程中的损耗管理：正常损耗率的标准是什么？损耗物料的处理方式（如回收利用、废弃等）是什么？异常损耗的界定及处理流程是什么？
    - 沼气作为自耗燃料，其消耗量如何计量、记录？是否有专门的计量设备（如流量计）？
    

### （五）工费归集与管理

1. 人工费用：
    
    - 生产人员的岗位设置（如操作工、技术员、质检员等）及薪酬结构（如固定工资、计件工资、绩效工资等）是什么？
    - 人工成本的分摊依据是什么？（如按生产工时、产品产量、生产批次等）
    - 生产工时的记录方式是什么？（如手工记录、打卡记录、设备联动记录等）是否区分直接生产工时和间接生产工时？
    
2. 制造费用：
    
    - 制造费用包含哪些明细项目？（如设备折旧费、水电费、维修费、燃料费、车间管理费等）
    - 各项制造费用的归集方式是什么？是否有明确的归集口径和责任部门？
    - 制造费用的分摊标准是什么？（如按生产工时、机器工时、原材料消耗金额等）
    

### （六）产品入库管理

1. 入库流程：
    
    - 产品完工后，入库的触发条件、申请流程及审批节点是什么？
    - 入库检验要求：是否对完工产品进行质量检验？检验项目（如养分含量、含水率、粒度等）、检验标准及合格判定规则是什么？
    - 检验合格与不合格产品的处理方式：合格产品直接入库；不合格产品是返工、报废还是降级处理？
    
2. 入库计量与记录：
    
    - 入库产品的计量方式是什么？（如按重量、数量等）计量工具及精度要求是什么？
    - 入库记录包含哪些核心信息？（如产品名称、规格、批次、数量、生产日期、入库日期、质检结果等）记录方式是手工还是系统录入？
    
3. 库存管理：
    
    - 成品库的库位划分规则是什么？（如按产品类型、批次、库龄等）
    - 库存盘点周期及方式是什么？（如月度盘点、年度盘点、循环盘点）盘点差异的处理流程是什么？
    

### （七）成本核算管理

1. 成本核算方法：
    
    - 当前采用的成本核算方法是什么？（如品种法、分批法、分步法）是否符合企业业务实际需求？
    - 成本核算周期是什么？（如按月、按批次）
    
2. 成本构成与归集：
    
    - 产品成本的核心构成要素有哪些？（如原材料成本、人工成本、制造费用、燃料动力成本等）
    - 原材料成本：如何归集不同批次、不同种类原材料的采购成本？采购运输费、仓储费等是否计入原材料成本？
    - 沼气作为自耗燃料，其成本如何核算及分摊至有机肥产品中？
    
3. 成本分配与结转：
    
    - 间接费用（如车间管理费、设备折旧费等）的分配标准是什么？是否合理？
    - 生产过程中的在产品如何核算？在产品的盘点频率及计价方法是什么？（如约当产量法、定额成本法等）
    - 完工产品成本与在产品成本的划分标准是什么？
    
4. 成本分析：
    
    - 是否定期开展成本分析？分析维度有哪些？（如产品成本分析、批次成本分析、成本差异分析等）
    - 成本分析结果的应用场景是什么？（如定价参考、成本控制、工艺优化等）
    

### （八）产品销售管理

1. 销售模式：
    
    - 主要销售渠道有哪些？（如直销、经销商销售、电商销售等）不同渠道的定价策略、结算方式是什么？
    - 是否存在定制化产品销售？定制化产品的生产计划、BOM 调整、定价方式是什么？
    
2. 销售订单管理：
    
    - 销售订单的接收、审核、执行流程是什么？
    - 销售订单是否与生产计划直接关联？订单变更（如数量、交货期调整）的处理流程是什么？
    
3. 发货与结算：
    
    - 产品发货的触发条件、流程及单据是什么？发货时如何确认产品批次、数量？
    - 结算方式有哪些？（如现销、赊销、预付款等）不同结算方式的收款周期及对账流程是什么？
    - 售后服务管理：是否存在产品退换货情况？退换货的原因、处理流程及成本核算方式是什么？
    

### （九）业务难点与优化需求

1. 生产环节难点：
    
    - 原材料（羊粪、粪污、秸秆）的供应稳定性、质量一致性是否存在问题？如何应对？
    - 发酵工艺的周期长、受环境影响大，是否导致生产计划难以精准执行？
    - 沼气的产生量与消耗量如何精准匹配？是否存在供需失衡问题？
    
2. 成本核算难点：
    
    - 原材料（尤其是粪污、秸秆）的计量、计价是否存在困难？
    - 间接费用分摊标准是否合理？是否存在成本核算不准确的情况？
    - 自耗沼气的成本核算是否清晰？如何确保其成本合理分摊？
    
3. 管理痛点：
    
    - 当前业务流程中是否存在重复劳动、效率低下的环节？（如手工记录数据、多次录入等）
    - 各部门之间的信息传递是否顺畅？是否存在信息滞后、数据不一致的问题？
    - 现有管理工具（如 Excel、简易系统）是否满足业务发展需求？存在哪些局限性？
    
4. 系统优化需求：
    
    - 希望 SAP 系统在生产管理、成本核算等方面解决哪些核心问题？
    - 是否有特殊的业务场景需要 SAP 系统支持？（如个性化报表、预警功能等）
    

## 四、调研方式与工具

2. 资料收集：收集生产计划、产品 BOM 清单、生产工艺文件、领料单、入库单、成本核算表、销售合同等相关业务资料。
3. 现场观察：实地走访生产车间、仓库、沼气生产设施等，观察实际业务操作流程。
4. 问卷调研：针对部分标准化问题，发放调研问卷收集相关信息。

# SAP 实施项目 - 有机肥生产企业全业务链调研大纲

## 一、调研总则

### （一）调研目标

1. 全景梳理有机肥生产企业从 “原材料采购→生产制造（含沼气自耗）→产品入库→成本核算→产品销售→售后服务” 全业务链条的流程逻辑、管理规则及数据流转关系。
2. 明确各业务环节的核心需求、管控要点及现存痛点，为 SAP 系统（MM、PP、CO、SD、FI 等模块）的配置、集成及个性化开发提供精准依据。
3. 确保 SAP 系统方案与企业业务深度适配，实现 “业财一体化、数据全贯通、管理精细化”，解决有机肥行业特有的生产、成本、供应链管理难题。

### （二）调研范围

1. 业务范围：覆盖采购管理、库存管理、生产计划与执行、沼气生产与自耗、质量管理、成本核算、销售管理、财务管理、售后服务等全业务链。
2. 组织范围：生产部门、采购部门、仓储部门、质检部门、销售部门、财务部门、运维部门、管理层等相关业务单元及岗位。
3. 数据范围：产品主数据、物料主数据、BOM 数据、工艺路线数据、成本要素数据、客户 / 供应商主数据、订单数据、库存数据等核心业务数据。

### （三）调研核心原则

1. 全链条贯通：聚焦各业务环节的衔接逻辑（如采购与领料、生产与成本、销售与库存的联动），避免孤立调研。
2. 行业特殊性：重点关注有机肥行业原材料特性（如羊粪、粪污等生物质原料）、生产工艺特性（如发酵周期长、沼气自耗）、成本核算特殊性等。
3. 问题导向：挖掘当前业务中效率低下、数据不透明、管控缺失等痛点，明确系统需解决的核心问题。
4. 前瞻性：结合企业发展规划，调研未来 1-3 年的业务扩展需求（如新产品线、新销售渠道、产能扩张等），确保系统具备扩展性。

## 二、调研大纲核心结构及核心问题

### 第一部分：基础信息与业务全景调研

#### 1. 企业基本信息

- 核心问题：
    
    1. 企业组织架构（总部、生产基地、销售分支机构等）及权责划分？各生产基地的产能、产品类型、生产布局是什么？
    2. 企业战略规划（如未来是否拓展有机无机复混肥、生物刺激素等产品，是否新增生产基地或销售区域）？
    3. 现有 IT 系统现状（如是否使用 ERP、MES、WMS 等系统，各系统功能覆盖、数据流转、存在的问题；是否需要与 SAP 系统集成）？
    

#### 2. 业务全景概览

- 核心问题：
    
    1. 企业核心业务流程链条的简要描述（从原材料采购到产品销售的全流程概览）？
    2. 各业务环节的核心管理目标（如采购环节的成本控制、生产环节的质量稳定、销售环节的渠道拓展等）？
    3. 当前全业务链中最突出的 3-5 个管理难点或痛点是什么（如原材料计量困难、生产计划不准、成本核算不精准等）？
    

### 第二部分：供应链前端调研（采购 + 库存）

#### 1. 采购管理

- 核心问题：
    
    1. 原材料分类及采购模式：
        
        - 核心原材料（羊粪、粪污、秸秆）的采购渠道（如农户、养殖场、合作社等）、采购周期、供应稳定性如何？
        - 辅料（如菌种、腐熟剂、包装材料）、备品备件的采购模式（集中采购 / 分散采购、框架协议采购 / 订单采购）是什么？
        
    2. 采购流程：
        
        - 采购需求的触发依据（生产计划、安全库存、销售订单）是什么？采购申请、审批、订单下达、订单跟踪的流程及权限划分？
        - 原材料验收流程：验收标准（如羊粪含水率、秸秆杂质率）、验收方式（抽样检验 / 全检）、不合格原材料的处理方式（退货、让步接收、折价）？
        
    3. 采购结算：
        
        - 不同原材料的定价方式（如羊粪按重量计价、秸秆按体积 + 质量分级计价）、结算周期（现结、月结、预付款）是什么？
        - 采购费用（运输费、装卸费、仓储费）的承担方及核算方式（是否计入原材料成本）？
        
    

#### 2. 库存管理

- 核心问题：
    
    1. 仓库布局与库位管理：
        
        - 仓库分类（原材料库、辅料库、在制品库、成品库、废料库、沼气存储设施）及库位划分规则（如原材料按来源、类型分区）？
        - 生物质原材料（如羊粪、秸秆）的存储条件（如通风、防雨、防异味）及存储周期要求？
        
    2. 物料收发存管理：
        
        - 原材料入库：计量方式（地磅称重、体积测量）、入库单据类型及核心字段、数据记录方式（手工 / 系统）？
        - 生产领料：领料触发条件（生产订单、工单）、领料流程（申请 - 审批 - 发放）、领料计量精度要求？
        - 库存盘点：盘点周期（月度 / 季度 / 年度、循环盘点）、盘点方式（手工盘点 / 系统辅助盘点）、盘点差异处理流程及权限？
        
    3. 特殊物料管理：
        
        - 沼气的存储方式、计量工具（流量计）、消耗量记录方式、损耗控制标准？
        - 生产过程中产生的废料（如发酵残渣）、副产品（如沼气发电余能）的库存管理及处置方式（回收利用、销售、废弃）？
        
    

### 第三部分：生产管理调研（计划 + 工艺 + 执行）

#### 1. 产品与 BOM 管理

- 核心问题：
    
    1. 产品种类与规格：
        
        - 有机肥产品的具体品类（颗粒肥、粉剂肥、液体肥、专用肥如蔬菜专用肥 / 果树专用肥）、规格参数（养分含量 N-P-K、包装规格 25kg / 袋、50kg / 袋）？
        - 是否存在副产品（如沼气、发酵残渣制成的有机肥下脚料）？副产品的定义、用途（自耗、销售、回收）？
        
    2. 产品 BOM 结构：
        
        - 各产品的 BOM 层级（单层 / 多层）、物料构成（主原料、辅料、包装材料、沼气）？
        - 核心原材料的消耗定额（如生产 1 吨颗粒肥需羊粪 0.8 吨、秸秆 0.3 吨、菌种 0.005 吨）制定依据（实验数据 / 生产经验）及调整机制？
        - 沼气作为自耗燃料，是否纳入 BOM？若纳入，其消耗定额（如干燥 1 吨产品需沼气 50m³）如何确定？
        - 替代物料管理：是否存在原材料替代场景（如羊粪短缺时用牛粪替代）？替代规则（如比例限制、质量要求）及触发条件？
        
    

#### 2. 生产计划管理

- 核心问题：
    
    1. 计划层级与编制依据：
        
        - 是否区分主生产计划（MPS）、车间作业计划（PAC）？计划编制周期（月度 / 周 / 日）及编制依据（销售订单、市场预测、库存水平、设备产能）？
        
    2. 计划执行与调整：
        
        - 生产计划如何下达至车间（纸质订单 / 系统指令）？车间如何反馈执行进度？
        - 计划调整场景（销售订单变更、原材料短缺、设备故障、发酵工艺异常）及调整流程、权限？
        
    3. 批次管理：
        
        - 是否采用批次管理？批次编码规则（如包含生产日期、生产车间、原材料批次）？
        - 批次追溯要求：是否需要实现 “原材料批次→生产批次→成品批次→销售订单” 的全链条追溯？追溯需包含哪些核心信息（如原材料来源、发酵参数、质检结果）？
        
    

#### 3. 生产工艺与执行

- 核心问题：
    
    1. 核心生产工艺流程：
        
        - 有机肥完整工艺路线（原料预处理→发酵→腐熟→粉碎→混合→造粒→干燥→筛分→包装）的各环节操作要求、关键技术参数（发酵温度 55-60℃、发酵周期 15-20 天、粉碎粒度 20 目、含水率≤15%）？
        - 沼气生产工艺（原料发酵→沼气收集→脱硫脱水→存储→输送）与有机肥生产工艺的衔接逻辑（如发酵环节同步产生沼气，输送至干燥环节作为燃料）？
        
    2. 生产执行与记录：
        
        - 各工艺环节的执行记录方式（手工填写报表 / PLC 自动记录 / MES 系统录入）？记录的核心数据（如发酵时间、温度、物料投入量、产出量）？
        - 生产设备管理：主要设备（发酵罐、粉碎机、造粒机、干燥机、沼气发生器）的产能、运行参数、维护周期、故障处理流程？设备运行数据是否与生产记录联动？
        
    3. 生产异常管理：
        
        - 常见生产异常（如发酵不充分、造粒合格率低、沼气供应不足）的界定标准及处理流程（如返工、报废、调整工艺参数）？
        - 异常处理的责任部门及权限划分？
        
    

#### 4. 领料与生产过程物料流转

- 核心问题：
    
    1. 生产领料：
        
        - 领料是否按生产订单分批次领取？领料时如何核对原材料批次与生产批次的对应关系？
        - 原材料损耗管理：正常损耗率（如发酵环节损耗率 5%）的标准是什么？异常损耗（如物料浪费、污染）的界定及处理流程？
        
    2. 工序间物料流转：
        
        - 各工艺环节之间的物料移交如何记录（如工序交接单）？移交时是否需要质检？
        - 在制品管理：在制品的盘点频率（每日 / 每周）、计价方式（定额成本法 / 约当产量法）？
        
    

#### 5. 产品入库管理

- 核心问题：
    
    1. 入库触发与流程：
        
        - 产品完工后，入库的触发条件（生产订单完成、质检合格）、入库申请流程及审批节点？
        
    2. 入库质检：
        
        - 成品检验项目（养分含量、含水率、粒度、pH 值）、检验标准、合格判定规则？
        - 检验合格与不合格产品的处理：合格产品入库；不合格产品返工（返工流程、成本核算）、报废（报废流程、损失承担）、降级处理（如次品肥单独定价销售）？
        
    3. 入库计量与记录：
        
        - 成品入库的计量方式（称重、按件计数）、入库单据核心字段（产品名称、规格、批次、数量、生产日期、质检结果）？
        
    

### 第四部分：成本核算调研

- 核心问题：
    
    1. 成本核算基础：
        
        - 当前采用的成本核算方法（品种法、分批法、分步法）？核算周期（按月 / 按批次）？
        - 成本核算对象（按产品品种、生产批次、生产线）？
        
    2. 成本构成与归集：
        
        - 产品成本的核心构成要素（原材料成本、人工成本、制造费用、燃料动力成本（沼气）、废品损失）？
        - 原材料成本：不同批次、不同来源原材料的采购成本如何归集？损耗物料（正常损耗 / 异常损耗）的成本处理方式？
        - 人工成本：生产人员岗位划分（操作工、技术员、质检员）、薪酬结构（固定工资 / 计件工资 / 绩效工资）？人工成本的分摊依据（生产工时、产品产量、生产批次）？生产工时的记录方式（手工打卡、设备联动记录）？
        - 制造费用：包含的明细项目（设备折旧费、水电费、维修费、车间管理费、辅料消耗）？各项费用的归集口径及责任部门？
        - 沼气成本：沼气的生产成本（原材料分摊、设备折旧、能耗）如何核算？作为自耗燃料，如何分摊至有机肥产品中（按产品耗气量、生产工时）？
        
    3. 成本分配与结转：
        
        - 间接费用（制造费用、沼气成本）的分摊标准（如按生产工时、机器工时、原材料消耗金额）是否合理？
        - 在产品成本核算：在产品的盘点频率、计价方法（约当产量法、定额成本法）？完工产品与在产品的成本划分标准？
        - 副产品成本处理：沼气、发酵残渣等副产品的成本如何分摊（如按售价法、实物量法）？
        
    4. 成本分析与控制：
        
        - 是否定期开展成本分析？分析维度（产品成本对比、批次成本差异、成本要素占比）？
        - 成本控制的核心指标（如单位产品原材料消耗、单位产品制造费用）？是否有成本预警机制？
        
    

### 第五部分：销售与售后服务调研

#### 1. 销售管理

- 核心问题：
    
    1. 销售模式与渠道：
        
        - 主要销售渠道（直销给农户、经销商销售、商超销售、电商销售、政府采购）？各渠道的销售占比、定价策略（出厂价、批发价、零售价）、结算方式（现销、赊销、预付款、承兑汇票）？
        - 是否存在定制化销售（如按客户需求调整养分含量、包装）？定制化产品的订单处理流程？
        
    2. 销售订单管理：
        
        - 销售订单的接收方式（线下合同、线上平台、电话订单）、审核流程及权限？
        - 销售订单与生产计划的联动逻辑（如订单交期确定依据、插单处理流程）？
        - 订单变更（数量、交期、产品规格调整）及订单取消的处理流程、责任界定？
        
    3. 发货与结算：
        
        - 发货流程：发货触发条件（订单审核通过、收到货款 / 预付款）、发货申请、拣货、复核、装车、出库单据（提货单、出库单）的流转？
        - 发货批次确定原则（先进先出、客户指定批次）？如何确保销售批次与生产批次的追溯关联？
        - 销售结算：开票流程（开票依据、开票时间）、对账流程（月度对账 / 订单对账）、收款跟踪及逾期收款处理？
        
    

#### 2. 售后服务

- 核心问题：
    
    1. 退换货管理：
        
        - 退换货的触发条件（产品质量问题、包装破损、客户需求变更）？退换货申请、审核、退货验收、退款 / 换货流程？
        - 退货产品的处理方式（返工、报废、折价销售）？相关成本的核算方式？
        
    2. 客户反馈与质量追溯：
        
        - 客户反馈（如产品效果不佳、养分不达标）的收集渠道及处理流程？
        - 当客户反馈质量问题时，如何实现从销售订单反向追溯至生产批次、原材料批次及生产工艺参数？
        
    

### 第六部分：财务管理调研

- 核心问题：
    
    1. 总账与应收应付：
        
        - 会计核算制度（企业会计准则）、会计期间（自然月）、记账本位币？
        - 应收款管理：客户信用额度设置、账龄分析周期、坏账计提政策？
        - 应付款管理：供应商付款周期、付款申请流程、应付账款账龄分析？
        
    2. 资产管理：
        
        - 固定资产（生产设备、沼气设施、仓库、运输车辆）的分类、折旧方法（年限平均法、工作量法）、折旧年限、残值率？
        - 固定资产的新增、折旧计提、维修、处置（报废、变卖）的核算流程？
        
    3. 报表需求：
        
        - 管理层需要的核心报表（生产报表、库存报表、成本报表、销售报表、财务报表）？报表的呈现形式（表格、图表）、输出频率（日报 / 周报 / 月报）？
        - 是否需要自定义报表（如有机肥产品批次成本跟踪表、沼气消耗与生产成本关联表）？
        
    

### 第七部分：业务难点与系统需求调研

#### 1. 现有业务难点

- 核心问题：
    
    1. 采购环节：是否存在原材料供应不稳定、质量波动大、计量不准确、采购成本难以控制等问题？
    2. 生产环节：是否存在生产计划与实际执行偏差大、发酵工艺难以精准控制、在制品管理混乱、沼气供需失衡等问题？
    3. 成本核算：是否存在原材料损耗难以统计、间接费用分摊不合理、沼气成本核算不清晰、产品成本精准度低等问题？
    4. 销售环节：是否存在订单跟踪不及时、批次追溯困难、客户信用风险控制不足等问题？
    5. 跨部门协同：是否存在各部门数据不互通（如生产数据与财务数据脱节、销售订单与生产计划不同步）、信息传递滞后等问题？
    

#### 2. SAP 系统核心需求

- 核心问题：
    
    1. 模块功能需求：
        
        - MM 模块：是否需要支持生物质原材料的特殊采购流程、库存计量、批次管理？
        - PP 模块：是否需要支持基于发酵周期的生产计划编制、工艺参数记录、沼气自耗联动核算？
        - CO 模块：是否需要支持批次成本核算、沼气成本分摊、间接费用精准分配？
        - SD 模块：是否需要支持多渠道销售管理、订单与生产计划联动、全批次追溯？
        
    2. 集成需求：
        
        - 是否需要 SAP 系统与 MES 系统（生产工艺数据采集）、WMS 系统（库存精准管理）、计量设备（地磅、流量计）集成？
        - 各模块间数据流转需求（如采购订单→入库单→领料单→生产订单→成品入库单→销售订单→发票）？
        
    3. 个性化需求：
        
        - 是否需要自定义报表（如原材料质量分级统计、发酵工艺参数分析、产品成本差异对比）？
        - 是否需要特殊功能（如沼气消耗预警、生产批次追溯跟踪、客户信用额度预警）？
        
    

## 三、调研方式与工具

1. 访谈调研：一对一访谈（关键岗位负责人）、小组访谈（跨部门协同环节），记录访谈纪要。
2. 资料收集：收集企业现有制度文件（采购管理制度、生产工艺文件、成本核算制度）、业务单据（采购订单、领料单、生产报表、销售合同）、报表模板等。
3. 现场观察：实地走访生产车间、仓库、沼气设施、质检部门，观察实际业务操作流程。
4. 问卷调研：针对标准化问题（如岗位设置、报表需求），发放调研问卷收集信息。

## 四、调研输出

1. 全业务链调研报告：含业务流程梳理、核心数据清单、管理需求、现存痛点及优化方向。
2. 业务流程图：绘制各环节详细业务流程图（含跨部门衔接逻辑）。
3. 系统需求规格说明书：明确 SAP 各模块配置需求、集成需求、个性化开发需求。
4. 数据字典：整理产品、物料、客户、供应商、成本要素等核心主数据字典。
